# Data dictionary

Generated by `marg data-dictionary` (output schema version 2). Do not edit by hand.

Every run folder holds these files (plan/04-data-outputs-analytics.md).

## manifest.json

Run identity and provenance (JSON, not Parquet).

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| run_hash | string |  | blake3 of resolved spec + seed + version; the run's identity |
| output_hash | string |  | blake3 of every step's state; equal ⇔ bitwise-identical run |
| status, error | string |  | ok / failed / timeout; why a run failed |
| experiment | object? |  | experiment, run_id, point, arm, rep (absent for ad-hoc runs) |
| calibration_stages | list<u8> |  | frozen calibration stages applied (`calibration` layer) |
| live | object? |  | live sessions only: session, initial_run_hash, commands, state_commands, replay_verified |
| seed, threads, git_sha, git_dirty, marg_version, wall_time_s, … |  |  | see `marg_io::RunManifest` (run format version 2) |

## params.parquet

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| path | utf8 |  | register path |
| value / value_si | utf8 (JSON) | register unit / SI | scalar or distribution; null = unset |
| unit / si_unit | utf8 |  | units of `value` and `value_si` |
| mean_si | f64 | SI | mean of the value |
| grade | utf8 |  | A, B, C, A/B, B/C |
| role, stage | utf8, i32 |  | fix / fit (stage 0–7) / sweep / scenario |
| source, guide | utf8 |  | citation and guide section |
| set_by, fix_overridden | utf8, bool |  | base / calibration / scenario / experiment / live |

## events.parquet

One row per discrete event.

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| t, kind, agent_id | f64, utf8, u64 | s | kinds so far: collision_guard, lateral_move, object_added, object_removed, parking_manoeuvre, stop_anywhere, stop_anywhere_standing (agent_id is 2⁶⁴ − 1 for the object and parking events) |
| ribbon, s, y | utf8, f64, f64 | m | where |
| attrs | utf8 (JSON) |  | collision_guard: other_id, overlap_m, cut_back_s, cut_back_y against a vehicle; other = object and object (its id) against a road object; other = edge and cut_back_s when the kerb of a narrowing road stopped the vehicle short. object_added, object_removed: object (id), kind (obstacle, parked_vehicle, parking_manoeuvre), length, width, with the footprint's centre in ribbon, s, y. parking_manoeuvre (when it begins): zone, object (the id of the footprint that blocks the strip), action (park or unpark), duration_s, waited_s (how long it waited for the strip to be clear). stop_anywhere (a vehicle decides to stop, ADR-0014): rate_per_km, multiplier (the attractor's), pull_over, pull_over_probability, dwell_s, stop_in_m. stop_anywhere_standing (it has come to a stand): pull_over, kerb_gap_m, until (s). lateral_move (only with `observers.lateral.log_decisions = 1`): target and the utility terms utility, own, polite, comfort, cost (m/s²) |

## effective_width.parquet

One row per effective-width observer (`outputs.effective_width`) and bin along the road, over the measured period. Written only when a scenario has such an observer. `W_eff = W − Σ w_i − c_shy` (G§6.2) is not used by the model: the table sets what the clearance model predicts beside what the vehicles did.

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| observer_id, ribbon | utf8 |  |  |
| s_from, s_to | f64 | m | the bin |
| road_width | f64 | m | mean carriageway width over the bin |
| blocked_width, free_width | f64 | m | width taken by road objects (footprints, plus strips between a footprint and the kerb or another footprint that are narrower than the narrowest vehicle type), averaged along the bin and over time; the rest |
| shy_desired, shy_minimum | f64? | m | desired and minimum lateral clearance (ADR-0010 §1) to the nearest object, averaged over the time vehicles spent beside one |
| effective_width_model | f64? | m | free_width − shy_desired |
| shy_observed, shy_observed_min | f64? | m | the gap to the nearest object that vehicles beside one were within for 5% of their time; the smallest gap seen |
| effective_width_observed | f64? | m | free_width − shy_observed |
| used_lo, used_hi | f64? | m | lateral band covered by vehicle bodies |
| time_beside, time_spent | f64 | veh·s | time vehicles spent beside an object, and in the bin |
| mean_speed | f64? | m/s | space-mean speed in the bin |

## conflicts.parquet

One row per conflict episode: consecutive steps in which two vehicles' time to contact, as oriented rectangles at constant velocity, was under `observers.conflict.ttc_threshold` (ADR-0010 §6). A vehicle has one open episode at a time, with the neighbour ahead of it whose time to contact is shortest.

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| t_start, t_end | f64 | s | first and last step under the threshold |
| agent_id, other_id | u64 |  | the vehicle behind (earlier along the ribbon) and the other one |
| class, other_class | utf8 |  |  |
| kind | utf8 |  | rear_end, sideswipe or head_on: the axis the bodies close on last |
| min_ttc | f64 | s | minimum time to contact in the episode |
| max_drac | f64? | m/s² | maximum deceleration rate to avoid the crash, closing speed² / (2 · gap) along the approach axis; null if never defined |
| ribbon, s, y | utf8, f64, f64 | m | where agent_id was at the minimum |

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| kpis: run_hash, seed, throughput_veh_h, delay_mean_s, delay_p95_s, … | f64 |  | see `Simulation::kpis`; measured window excludes warm-up |
| trajectories: t, agent_id, ribbon, s, y | f64, u64, utf8, f64, f64 | s, m | ribbon frame |
| trajectories: x_world, y_world, heading | f64 | m, rad | world frame; heading is the body's (road direction plus its own turn) |
| trajectories: v, v_lat, a | f64 | m/s, m/s, m/s² | speed along the ribbon, lateral speed (+ left of travel), acceleration |

## commands.parquet (live sessions)

One row per command of a live viewer session (plan P4.1). With `scenario.yaml`, `params/` and the seed it is the whole session: `marg replay` re-runs it headless and checks the output hash. Only accepted `set_param`, `resample`, `add_object` and `remove_object` rows change the run.

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| seq | u64 |  | position in the log |
| step, t | u64, f64 | s | steps completed and simulated time when it took effect (acts before step `step + 1`) |
| wall_s | f64 | s | wall-clock time since the session started (informational) |
| cmd | utf8 |  | set_param, resample, add_object, remove_object, play, pause, step, speed, select_agent, breakpoint, … |
| args | utf8 (JSON) |  | arguments; values in register units |
| accepted, message | bool, utf8 |  | outcome or refusal reason |

## index.parquet (experiment folder)

Written by `marg collect`: one row per run-list entry of an experiment, with the run's status. Run folders sit at `scenario=<s>/point=<p>/arm=<a>/rep=<r>/run=<hash>/`; `design.parquet` gives each point's factor values.

| Column | Type | Unit | Meaning |
| --- | --- | --- | --- |
| run_id, run_hash, experiment | u64, utf8, utf8 |  | position in `runs.jsonl`; identity |
| scenario, point, arm, rep, seed | utf8, u64, utf8, u64, u64 |  | Hive partition keys and the run's seed |
| path, tables | utf8 |  | run folder (relative); Parquet tables present |
| status, error | utf8 |  | ok / failed / timeout / corrupt / stale / missing |
| wall_time_s, output_hash, marg_version, git_sha, host, agent_steps | f64?, utf8?, … | s | from the run's manifest |
